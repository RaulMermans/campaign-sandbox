# Product Spec

Campaign Sandbox is an AI-assisted creative strategy workspace for teams turning unclear campaign briefs into decision-ready plans.

Users are creative strategists, founders, brand leads, and small campaign teams. The core loop is: messy brief, normalized strategy brief, strategic tension, route generation, synthetic audience simulation, scoring, pre-mortem, comparison, human route selection, execution plan, export.

MVP scope includes one mocked campaign workflow, schemas, trace timeline, route comparison, and docs. Non-goals include authentication, billing, real database persistence, real LLM calls, PDF export, visual workflow editing, and automated media buying.
